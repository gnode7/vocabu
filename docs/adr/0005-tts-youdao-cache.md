# TTS：有道非官方语音接口 + 两级本地缓存 + 失败回退

MVP 的语音播报采用有道词典的非官方语音接口（dict.youdao.com/dictvoice，免 key），并接受其随时变更/限流的风险——这是该体量应用的标准取舍。风险控制：`:core` 定义 `TtsClient` 接口，desktopApp 提供有道实现；更换服务（如 Edge TTS）只是换实现类。拼写播报按字母逐个请求的成本通过**两级缓存**消除：字母音频（26 个 + 变体）永久缓存本地，整词/词组读音走 LRU 缓存（上限约 200 条）——重复播报零网络、零延迟、离线可用。TTS 请求失败时静默跳过该段播报（不阻断操作）；听写等依赖「播报结束」作计时起点的场景，失败时回退到词条展示时刻。

# 考察双面同判、全量落账（含未到期面）

考察工作集按考核面筛选（到期或缺面），但听写一次交互**同时判定两个考核面**（听→拼、英→中）。由此产生粒度错位：一个词可能仅因英→中到期进入工作集，其未到期的听→拼面也被作答、评级、展示。决策：**两面全部落账**——未到期面的本次评级等效于一次提前复习，SM-2 据实绩推后其到期时间；尚无记录的面顺带覆盖「缺面」状态。被否掉的备选：**展示不落账**（未到期面只显示评级不写库——展示线与账本线分离，认知与实现双份复杂度，且「练了不计」违背「考=复习」直觉）；**只判到期面**（另一框隐藏不计——听写双框交互崩塌）。已知代价：各面到期节奏会被听写逐渐拉齐（两面在同一词上总被同时考核）——这与「一次学习事件同时锻炼两个能力面」的真实语义一致，可接受；「到期」的语义弱化为「进入工作集的触发器」而非「唯一考核时机」。此决策与 ADR 0004（按面分账）正交：分账不变，落账策略为全量。

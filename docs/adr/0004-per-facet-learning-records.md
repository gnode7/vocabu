# 学习记录按考核面分账（三账本），听写双评分

PRD 原稿将一个词的全部记忆收敛为一条 LearningRecord（wordId UNIQUE），英译中/中译英/听写/默写的表现混记一本账。后果：轻松认读的词间隔被拉长后，连默写/听写也不再出现——但「认读」与「产出/拼写」是不同能力，被动词汇量大于主动词汇量是学习者的常态。决策：**按考核面（Facet）分账**，账本划分原则 = 一个「刺激→反应」对一本账：英→中（认读）、中→英（产出）、听→拼（听写）；UNIQUE(wordId, facet)。听写一次交互产出两个子评分（英文拼写部分→听拼账、中文释义部分→英中账），两部分分别计时判定。被否掉的备选：单账本（PRD 原稿——概念最简但产生跨能力串账，默写被认读成绩掩盖）；两账本 + 听写拼写并入中→英（听写拼写有音频助攻，混入「看中文写」的账本会造成跨模式乐观偏差）。已知代价：一个词最多三条调度线，「考全三面」的速度变慢——这是「科学记忆」意图内的行为，非遗漏。未来若简化，迁移路径：按 facet 聚合回单条记录。

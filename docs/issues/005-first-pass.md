# ISSUE-005 通览（首页）浏览与播报

**前置依赖**：ISSUE-004（导航骨架）、ISSUE-001（TtsClient/AudioPlayer Fake）
**目标**：PRD v1.2 §2.3 全量——今日词表全量分组展示 + 选择 + 播报联动。
**权威依据**：PRD v1.2 §2.3、§4（播报规格）；ADR-0005（TTS 接缝，本切片用 Fake）。

## 范围

1. **展示**（原「初步记忆」已并入通览，PRD 1.2 修订 #2）：今日词表全量，分三组——新词（默认展开）、复习（默认收拢）、补查（默认收拢），组标题带词数、点击展开/收拢；条目 = 英文、词性（如有）、音标（如有）、中文翻译；超区滚动
2. **选择**：鼠标悬停高亮 + 上下键在**可见条目**间移动（收拢分组内的条目不参与选择），初始选中第一条，高亮视觉区分
3. **播报**（PRD §4 播报顺序，段间停顿统一 **0.5s**（§2.3.3/§4.3），字母间 0.3s）：
   - 单词默认：英文读音 → 停 0.5s → 字母拼写（每字母间 0.3s）
   - 词组默认：英文读音 → 停 0.5s → 中文翻译
   - 触发：点击条目或空格键；设置「选中自动播报」生效
   - 播报内容按设置（单词：读音/拼写多选；词组：读音/翻译多选）
   - 播控规则（PRD §4.4）：重复触发取消重来、切换选中取消前一个、离开页面全取消；TTS 失败静默跳过
4. **零副作用**：本页不创建/更新任何 LearningRecord（PRD 修订 #13）

## TDD 关键用例

- 播报脚本生成纯函数：给定 word/设置 → 有序播报段列表（文本+语言+间隔），**段间 0.5s、字母间 0.3s 断言**，含 Fake 播放器断言顺序与取消语义
- 分组收拢/展开后，选中遍历仅覆盖可见条目（纯逻辑抽测）

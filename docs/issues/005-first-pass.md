# ISSUE-005 初步记忆

**前置依赖**：ISSUE-004（导航骨架）、ISSUE-001（TtsClient/AudioPlayer Fake）
**目标**：PRD §2.3 全量——新词浏览 + 选择 + 播报联动。
**权威依据**：PRD §2.3、§4（播报规格）；ADR-0005（TTS 接缝，本切片用 Fake）。

## 范围

1. **展示**：今日新词列表（不含复习词），同时展示条数可配置（1~今日新词数，默认 10）；条目 = 英文、词性（如有）、音标（如有）、中文翻译；超区滚动
2. **选择**：鼠标悬停高亮 + 上下键移动，初始选中第一条，高亮视觉区分
3. **播报**（PRD §4 播报顺序）：
   - 单词默认：英文读音 → 停 0.3s → 字母拼写（每字母间 0.3s）
   - 词组默认：英文读音 → 停 0.5s → 中文翻译
   - 触发：点击条目或空格键；设置「选中自动播报」生效
   - 播报内容按设置（单词：读音/拼写多选；词组：读音/翻译多选）
   - 播控规则（PRD §4.4）：重复触发取消重来、切换选中取消前一个、离开页面全取消；TTS 失败静默跳过
4. **零副作用**：本页不创建/更新任何 LearningRecord（PRD 修订 #13）

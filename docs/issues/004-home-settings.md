# ISSUE-004 通览（首页）+ 设置页

**前置依赖**：ISSUE-002（设置与词表查询）、ISSUE-001（工作集计数逻辑）
**目标**：通览（首页，直接展示今日词表全量 + 三入口导航）与设置页全部条目。
**权威依据**：PRD v1.2 §2.2.2、§2.3.1–2.3.3、§2.4.1、§2.5.1（入口计数）、§2.6、§5.5；prototype.html（通览/设置屏）。

## 范围

1. **通览（首页）**（`:app:shared`）：
   - 今日词表**直接展示全量**（不设「开始学习」入口）：分三组——新词（默认展开）、复习（默认收拢）、补查（默认收拢），组标题带词数、点击展开/收拢
   - 条目 = 英文、词性（如有）、音标（如有）、中文翻译 + 播报按钮；超区滚动
   - **三入口导航**：通览 / 回忆 N / 考察 M（计数 = 当前设置的方向/方式对应工作集词数，随设置变化）；词库、设置为普通链接入口；**无侧边栏**
2. **设置页**：PRD §2.6 全部设置项（六分组：学习计划/通览/播报设置/回忆/考察/TTS），类型与范围校验：
   - 每日新词数量 1~500；**每日补查数** 0~50（0 = 关闭）；回忆条数 1~今日词数
   - **回忆方向**单选：英→中 / 中→英 / 混合（默认混合）；**考察方式**单选：听写 / 默写 / 混合（默认混合）
   - 考察 Easy 1~120 秒、Good Easy+1~300 秒；**批改后自动回放开关**（correctionReplay，默认开启，#11）
   - 播报内容多选（单词：读音/字母拼写；词组：读音/中文翻译）、通览自动播报开关、
     回忆组：英→中-单词播报拼写、英→中-词组播报翻译、中→英-默认播报英文读音
   - TTS 服务下拉（有道词典；Edge TTS 置灰待后续）
   - **保存后立即生效**（下次进入功能用新值；按设计稿为显式「保存」按钮，保存时钳制并提示），保存至 AppSettings 单行表
3. 导航骨架：通览（首页）↔ 词库 ↔ 会话屏（回忆/听写/默写）↔ 设置

## TDD 关键用例

- 设置范围校验纯函数（越界钳制 vs 拒绝，按 PRD：数字输入钳到界内并提示）
- 单选设置（回忆方向/考察方式）持久化与读取
- 入口计数查询 = 按当前方向/方式的工作集过滤 size；修改设置后计数联动

## 验收

- [ ] PRD §2.3 / §2.6 验收标准逐条手动冒烟通过
- [ ] 首页计数与实际进入会话后的词数一致；切换回忆方向/考察方式后计数随之变化

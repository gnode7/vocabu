# ISSUE-004 学习首页 + 设置页

**前置依赖**：ISSUE-002（设置与词表查询）、ISSUE-001（工作集计数逻辑）
**目标**：学习首页（模式入口 + 今日计数）与设置页全部条目。
**权威依据**：PRD §2.2.1、§2.4.1（首页结构）、§2.6、§5.5。

## 范围

1. **学习首页**（`:app:shared`）：
   - 「开始学习」入口 + 今日词表规模（新词/复习/补齐三色计数）
   - 四模式入口卡（初步记忆 / 英译中 / 中译英 / 混合 / 听写 / 默写——按 PRD §2.4.1 展示各模式今日工作集计数，如「英译中 26 · 默写 8 · 听写 12」）
   - 各模式自由进入，无强制顺序；词表为空的模式入口置灰并给出原因
2. **设置页**：PRD §2.6 全部设置项，类型与范围校验：
   - 每日新词数量 1~500；缺面补齐 0~50；初步记忆条数 1~今日新词数；回忆条数 1~今日词数
   - 考察 Easy 1~120 秒、Good Easy+1~300 秒
   - 播报内容多选、自动播报开关、TTS 服务下拉
   - 修改立即生效（下次进入功能用新值），保存至 AppSettings 单行表
3. 导航骨架：首页 ↔ 词库 ↔ 学习流程 ↔ 设置

## TDD 关键用例

- 设置范围校验纯函数（越界钳制 vs 拒绝，按 PRD：数字输入钳到界内并提示）
- 模式计数查询 = 工作集过滤的 size

## 验收

- [ ] PRD §2.6 验收标准逐条手动冒烟通过
- [ ] 首页计数与实际进入模式后的词数一致

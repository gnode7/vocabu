# ISSUE-006 回忆巩固

**前置依赖**：ISSUE-004、ISSUE-005（列表/选择/播报组件复用）
**目标**：PRD v1.2 §2.4 全量——单一入口按「回忆方向」会话 + 隐藏区偷看 + 评级 + SM-2 会话内循环。
**权威依据**：PRD v1.2 §2.4.1–2.4.5；ADR-0004（评级去向）；ISSUE-001 工作集/混合分配；prototype.html（回忆屏）。

## 范围

1. **工作集**：回忆为单一入口，会话方向由设置「回忆方向」决定（英→中 / 中→英 / 混合，默认混合）。工作集 = 今日词表 ∩（当前方向对应考核面**到期或缺面**）：英→中→英→中面；中→英→中→英面；混合→两面任一。新词三面全缺全参与；**未到期的已建账考核面不提前评**
2. **列表交互**：同通览（布局/选择），列表**不展示词性/音标**；无眼睛图标、无方向徽章：
   - 条目中被隐藏的一侧即为偷看区：**按住隐藏区域**显示该条隐藏内容，松开恢复（隐藏区悬停显示「偷看 Q」tooltip）
   - **按住 Q 偷看当前选中条目**（不全部偷看），松开恢复
   - 偷看不影响 SM-2（不计入回忆）
3. **评级**：条目右侧为**四段式进度条**，列表表头标注「忘 · 熟练程度 · 熟」指示方向（段内无数值）；悬停第 N 段预览点亮、**按下固定评级** → 前 N 段全部点亮，颜色按评级**红（1=Forget）/ 橘（2=Hard）/ 黄（3=Good）/ 绿（4=Easy）**填充（记忆进度可视，快捷键映射与段位一致）；悬停段位显示 tooltip「忘记[1] / 困难[2] / 记得[3] / 熟练[4]」（键帽图标标注快捷键）；评级后条目**置灰保留不消失、可随时改评**（会话内以最后一次评级为准，文本淡显、进度条醒目）；首次评级后选中态自动移至下一条未评条目；SM-2 以最终评级更新**该条目分配方向对应考核面**的账本
4. **循环**（PRD §2.4.2 循环与结束）：全部评级后检查会话内到期词 → 有则重新洗牌开新轮，无则结束；可随时退出
5. **混合方向**：条目按可评方向随机分配（两面皆可评 50/50，单面可评则固定）；**方向由布局本身体现**（英→中隐藏中文侧、中→英隐藏英文侧），不设徽章
6. **中→英播报**：默认不播报，「中→英-默认播报」开启则播英文读音
7. **DailyStudyLog**：评级处经 **StudyLogRepository.increment 增量落账**当日行（新学=首次评级创建记录的词数、复习数、正确率口径按 Forget=不正确；分母 = **判定数**——与考核面账本粒度一致，PRD 1.2 #21）

## TDD 关键用例

- 会话循环状态机：全部评完→轮末检查→洗牌→结束（纯逻辑抽测）
- 评级去向：混合方向两方向分别入正确账本
- 评级映射（1=Forget … 4=Easy）与**改评覆盖**（会话内最后一次生效）；点亮规则纯函数（点 N → 前 N 段、单色填充）；首次评级自动下移至未评条目、全部评完触发轮末检查

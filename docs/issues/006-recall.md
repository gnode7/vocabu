# ISSUE-006 回忆巩固

**前置依赖**：ISSUE-004、ISSUE-005（列表/选择/播报组件复用）
**目标**：PRD §2.4 全量——三种回忆模式 + 偷看 + 评级 + SM-2 会话内循环。
**权威依据**：PRD §2.4.1–2.4.5；ADR-0004（评级去向）；ISSUE-001 工作集/混合分配。

## 范围

1. **工作集**：进入模式时按考核面过滤今日词表（英译中→英→中；中译英→中→英；混合→两面任一），新词全参与
2. **列表交互**：同初步记忆（布局/选择），按模式隐藏对应内容：
   - 英译中：隐藏中文（条目右侧「眼睛」按住显示该条中文，Q 键按住显示全部，松开隐藏；偷看不计入 SM-2）
   - 中译英：隐藏英文
3. **评级**：条目右侧 Easy/Good/Hard/Forget 四按钮 + 快捷键 1/2/3/4；评级后条目淡出移除，SM-2 更新**对应考核面**账本
4. **循环**（PRD §2.4.2 循环与结束）：全部评级后检查会话内到期词 → 有则重新洗牌开新轮，无则结束；可随时退出
5. **混合模式**：条目按可评方向分配并带标识（EN→ZH / ZH→EN），展示/播报/偷看/评级按方向适用
6. **中译英播报**：默认不播报，「中译英-默认播报」开启则播英文读音
7. **DailyStudyLog**：评级处静默 upsert 当日行（新学=首次评级创建记录的词数、复习数、正确率口径按 Forget=不正确）

## TDD 关键用例

- 会话循环状态机：移除→轮末检查→洗牌→结束（纯逻辑抽测）
- 评级去向：混合模式两方向分别入正确账本

# ISSUE-007 考察（听写双评分 + 默写）

**前置依赖**：ISSUE-004、ISSUE-001
**目标**：PRD §2.5 全量——单焦点考察，听写两段式双评分。
**权威依据**：PRD §2.5.1–2.5.3；ADR-0004；ISSUE-001 判定/时间评级纯函数。

## 范围

1. **听写**（PRD §2.5.2 重写版）：
   - 流程：播报英文 → 播报结束开始英文段计时 → 英文框回车 = 锁定（记录耗时）→ 焦点跳中文框开始中文段计时 → 中文框回车 = 提交
   - 允许先填中文（英文段计时 = 播报结束→英文锁定时刻，两段可重叠）
   - 留空提交 = 该部分 Forget；「Forget」按钮/4 键 = 两账本同记 Forget 并显示答案
   - 两部分独立判定+评级：英文段→听拼账、中文段→英中账；每框独立绿/红；有错展示正确答案；全对 1.5s / 有错 3s 自动前进
   - 计时起点回退：TTS 失败未播报时，起点 = 词条展示时刻（ADR-0005）
2. **默写**（PRD §2.5.3）：展示中文 → 单英文输入框 → 回车提交；计时起点=中文展示时刻；评级入中→英账
3. **工作集**：听写 = 今日词表 ∩（听拼 或 英中 到期或缺面）；默写 = ∩（中英 到期或缺面）
4. **循环**：同回忆巩固（轮末检查会话内到期、洗牌、退出）
5. **DailyStudyLog**：正确率口径（听写正确 = 两段全对才计正确）

## TDD 关键用例

- 两段计时状态机：正常顺序、先中文、留空、直接 Forget、TTS 失败回退（纯逻辑抽测）
- 评级去向映射（英文段/中文段 → 正确 facet）

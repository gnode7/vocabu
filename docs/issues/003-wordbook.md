# ISSUE-003 词库管理

**前置依赖**：ISSUE-002
**目标**：词库 CRUD + Excel 批量导入 + 搜索，PRD §2.1 全量。
**权威依据**：PRD v1.2 §2.1、§5.1；ADR 0007（词条身份）；CONTEXT.md（单词/词组判定）。

## 范围

1. **Excel 导入**（desktopApp 内用 Apache POI，解析逻辑抽成纯函数放 `:core` 便于测试）：
   - 列映射 A=单词 B=词性 C=翻译 D=音标（可选）；**首行表头无条件跳过**（v1.2 §2.1.1 格式规范，无关键词识别）
   - 重复词（**归一化 (text, pos) 联合判重**：文本忽略大小写、词性 trim/小写/去尾点；同 text 异 pos 共存，ADR 0007）跳过，不算错误
   - isPhrase = trim 后含空白字符（写库前计算）
   - 导入完成报告：成功 N、跳过重复 M、失败 K（列出行号与原因）
   - 1000 词 < 5 秒（PRD §6.1）
2. **手动 CRUD**：添加/编辑表单（单词、词性、翻译、音标），isPhrase 自动派生不暴露；重复添加按归一化 (text, pos) 拦截（同 text 异 pos 允许）；编辑触发 = 编辑按钮**或双击行**（v1.2 §2.1.2）；删除带确认——文案「确定删除选中的 N 个单词？此操作不可撤销。」，级联清记录；**支持批量选择删除（复选框 + 批量操作栏）**
3. **搜索**：中英文模糊匹配（SQL LIKE 前缀 + 包含，通配符转义）
4. **UI**：词库列表页（Compose，`:app:shared`），**词性筛选、排序（默认按字母，可切换按添加时间）**（v1.2 §2.1.2），滚动流畅（PRD §6.1：万词不卡）

## TDD 关键用例

- 导入解析纯函数：**表头无条件跳过**、列缺失、空行、重复（**归一化 (text,pos)**：同键拒、异 pos 收、'n.'/'N'/'n ' 同归一）、isPhrase 派生、音标可空
- 搜索：英文大小写、中文子串

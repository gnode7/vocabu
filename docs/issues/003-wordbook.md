# ISSUE-003 词库管理

**前置依赖**：ISSUE-002
**目标**：词库 CRUD + Excel 批量导入 + 搜索，PRD §2.1 全量。
**权威依据**：PRD §2.1、§5.1；CONTEXT.md（单词/词组判定）。

## 范围

1. **Excel 导入**（desktopApp 内用 Apache POI，解析逻辑抽成纯函数放 `:core` 便于测试）：
   - 列映射 A=单词 B=词性 C=翻译 D=音标（可选），首行表头自动跳过（包含「单词/word」等关键词）
   - 重复词（忽略大小写）跳过，不算错误
   - isPhrase = trim 后含空白字符（写库前计算）
   - 导入完成报告：成功 N、跳过重复 M、失败 K（列出行号与原因）
   - 1000 词 < 5 秒（PRD §6.1）
2. **手动 CRUD**：添加/编辑表单（单词、词性、翻译、音标），isPhrase 自动派生不暴露；重复添加拦截；删除带确认，级联清记录
3. **搜索**：中英文模糊匹配（SQL LIKE 前缀 + 包含）
4. **UI**：词库列表页（Compose，`:app:shared`），滚动流畅（PRD §6.1：万词不卡）

## TDD 关键用例

- 导入解析纯函数：表头识别、列缺失、空行、重复、isPhrase 派生、音标可空
- 搜索：英文大小写、中文子串

- [ ] 导入解析单测全绿

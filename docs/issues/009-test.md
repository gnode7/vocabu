# ISSUE-009 考察：听写 + 默写

**前置依赖**：ISSUE-002（设置与词表查询）、ISSUE-001（TtsClient/AudioPlayer Fake、SM-2 时间阈值评级）
**目标**：PRD v1.2 §2.5 全量——单一「考察」入口按「考察方式」执行：听写（双评分）、默写（单输入），提交批改模型 + 环形计时 + 上一个/下一个回看。
**权威依据**：PRD v1.2 §2.5.1–2.5.3、§2.6（考察阈值/回放设置）、§4（播报规格）；ADR-0004（评级去向）；交互细节另见设计原型（`prototype.html` 听写/默写两屏）。

## 范围

1. **入口与工作集**：考察为单一入口，方式由设置「考察方式」决定（听写 / 默写 / 混合，默认混合）。工作集 = 今日词表 ∩（对应考核面**到期或缺面**）：听写 → 听→拼 或 英→中；默写 → 中→英；混合 = 两部分并集，先听写后默写。入口计数 = 当前方式对应工作集词数，随设置变化
2. **听写（单焦点）**：播报 → 两输入框作答（可先中文后英文，Tab 切换）→ **两段回车**：第一次锁定当前框并切换焦点，第二次提交批改（按钮点击 = 直接提交）：
   - **每框独立倒计时圈**（输入框右侧）：颜色随该框累计耗时切换（Easy 绿 / Good 黄 / 走满变 Hard 橙）；焦点在哪个框哪个框计时，另一个暂停；批改后圈变对号/红叉徽章
   - 批改：答对的框右侧计时圈变**绿色对号徽章**；答错变**红叉徽章** + 输入框**红底红边框** + 正确答案绿色展示在**输入框右侧**（框内不显示勾叉）+ 短促告警音
   - 留空或答错 = 该部分 **Forget**；答对部分按该部分累计计时自动评级（焦点制分别计时：Easy / Good / Hard，阈值见设置）
   - 评级去向：英文部分 → 听→拼账本、中文部分 → 英→中账本；**词级评级**以四段式进度条展示（样式同回忆页，取两部分中较差者定级）
   - 答错时自动回放一次（英文 = 读音 + 字母拼写，中文 = 释义；受「批改后自动回放」开关控制，默认开启）
   - 判定后按钮变「下一个」，回车触发；「上一个」随时回看已答词判定结果（只读、不重复落账）；**无自动跳转、无逐条 toast**
3. **默写（单焦点）**：展示中文 → 单输入框作答 → **一次回车即提交**（判定规则同听写，只看英文；计时起点 = 中文展示时刻）；评级入中→英账本；独立倒计时圈 + 结果徽章同听写；提交 → 下一个 / 上一个回看、无自动跳转
4. **环形计时**：每输入框右侧独立圆圈（SVG 描边），播报/展示结束起走、Good 阈值走满一圈；Easy 阈值内为绿色、超过变黄、走满一圈变 Hard 橙色；批改后变为对号（绿）/红叉（红）徽章，提交按钮不再带圈
5. **设置联动**：考察阈值（Easy / Good）与「批改后自动回放」开关即时生效（下次进入对应功能时使用新值）
6. **DailyStudyLog**：评级处静默 upsert 当日行（新学 / 复习数 / 正确率口径按 Forget = 不正确，同 ISSUE-006）

## TDD 关键用例

- 批改纯函数：en/zh 输入 + **各部分累计计时** → (enLevel, zhLevel, wordLevel = min)（覆盖留空 = Forget、多释义中文匹配、大小写与空格折叠、阈值边界）
- 分别计时驱动：焦点切换 → 上一部分暂停 / 当前部分继续累计（纯逻辑抽测）
- 环形计时驱动：elapsed → 进度比例与颜色切换（Easy / Good 阈值边界、走满后冻结）
- 混合方式会话编排：听写队列耗尽 → 自动接默写队列 → 全部完成结束
- 上一个 / 下一个导航：只读回看不重复落账；首次评级计数不因回看变化

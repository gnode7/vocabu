# Vocabu 产品需求文档 (PRD)

> 版本：1.0 | 日期：2026-09-03 | 状态：草稿

---

## 1. 产品概述

### 1.1 产品定位

Vocabu 是一款辅助背英语单词和词组的桌面应用，通过科学的记忆方法（艾宾浩斯遗忘曲线 + SM-2 间隔重复算法）帮助用户高效记忆英语词汇，并提供多种回忆和考察方式检验记忆效果。

### 1.2 目标用户

- 需要背诵英语单词/词组的中国用户（考研、托福、雅思、GRE、日常学习等）
- 有自定义词库需求的用户（可导入自己的词汇列表）

### 1.3 核心价值

- **自定义词库**：用户自己决定背什么词，通过 Excel 导入
- **科学复习**：SM-2 算法自动安排复习时机，避免无效重复
- **多种检验方式**：从初步记忆到听写默写，循序渐进检验记忆效果
- **语音辅助**：TTS 播报读音和拼写，多感官记忆

### 1.4 MVP 范围

- 平台：Desktop（Windows/macOS/Linux，基于 Compose Multiplatform JVM 目标）
- 存储：纯本地存储（SQLite）
- 词库：单个全局词库
- TTS：在线 TTS 服务

## 2. 功能模块

### 2.1 词库管理

#### 用户故事

> 作为一名备考学生，我想导入一份 Excel 词汇表，这样我可以快速建立自己的词库开始背诵。

> 作为一名用户，我想手动添加/编辑/删除单词，这样我可以随时调整词库内容。

#### 2.1.1 Excel 批量导入

**格式规范**

| 列 | 字段 | 类型 | 必填 | 说明 |
|----|------|------|------|------|
| A | 单词/词组 | 文本 | 是 | 英文单词或词组，不区分大小写存储但保留原始大小写 |
| B | 词性 | 文本 | 否 | 如 n. / v. / adj. / adv. / prep. / conj. / pron. 等，可为空 |
| C | 中文翻译 | 文本 | 是 | 一个或多个中文释义，用逗号或分号分隔 |

- 第一行为表头，自动跳过
- 支持 `.xlsx` 格式（MVP）
- 文件编码：UTF-8

**导入规则**

- **去重策略**：以"单词/词组"文本为唯一键（忽略大小写），如果导入的词已存在于词库中，则**跳过**并提示用户有 N 个重复项
- **空行处理**：跳过空行
- **格式校验**：
  - A 列为空的行 → 跳过并记录
  - C 列为空的行 → 跳过并记录（翻译不能为空）
  - B 列为空 → 允许，pos 存为 null
- **导入结果反馈**：导入完成后展示统计——成功导入 N 个，跳过 M 个重复，忽略 K 个格式错误

**验收标准**

- [ ] 能正确解析符合格式规范的 .xlsx 文件
- [ ] 重复词被跳过，不产生重复数据
- [ ] 格式异常行被跳过，不影响其他行的导入
- [ ] 导入完成后展示详细的导入结果统计

#### 2.1.2 逐条管理

**添加单词**

- 弹出编辑表单（弹窗），字段：
  - 单词/词组（必填，文本输入）
  - 词性（选填，文本输入或下拉选择）
  - 中文翻译（必填，文本输入）
- 提交前校验：单词/词组和中文翻译不能为空
- 如果单词/词组已存在（忽略大小写），提示"该词已存在"，不执行添加

**编辑单词**

- 在列表中点击编辑按钮或双击行，打开编辑表单
- 编辑表单预填当前值
- 校验规则同添加

**删除单词**

- 支持单选删除（右键菜单或操作按钮）
- 支持批量选择删除（复选框 + 批量操作栏）
- 删除前弹出确认对话框："确定删除选中的 N 个单词？此操作不可撤销。"
- 删除单词时同步删除其关联的 LearningRecord

**搜索/筛选**

- 搜索框：支持按英文单词/词组（模糊匹配）和中文翻译（模糊匹配）搜索
- 筛选：可按词性筛选（如只看名词）
- 排序：默认按字母顺序，可切换为按添加时间

**验收标准**

- [ ] 能正确添加、编辑、删除单词
- [ ] 重复词添加被拦截
- [ ] 删除单词时关联的学习记录一并清除
- [ ] 搜索能正确模糊匹配中英文内容

### 2.2 学习计划

#### 用户故事

> 作为一名用户，我想设置每天背 20 个新词，系统自动帮我安排今天的学习任务。

#### 2.2.1 每日词量设置

- 在设置页配置"每日新词数量"，默认 20
- 范围：1 ~ 词库中尚未学习的总词数
- 修改后立即生效，影响后续的"今日词表"生成

#### 2.2.2 今日词表生成

**生成时机**：用户点击"开始学习"时生成

**生成规则**

1. **新词**：从词库中取出尚无 LearningRecord 的单词，按添加顺序取 `dailyNewWordCount` 个
2. **复习词**：从 LearningRecord 中取出 `nextReviewTime <= now` 的单词
3. **今日词表** = 新词 + 复习词

**特殊情况**

- 如果词库中没有未学习的新词 → 今日无新词，仅有复习词
- 如果没有到期复习的词 → 今日仅有新词
- 如果两者都没有 → 提示"今日无学习任务"，引导用户去词库添加单词
- 如果剩余新词不足 dailyNewWordCount → 取全部剩余新词

**验收标准**

- [ ] 今日词表正确包含新词和到期复习词
- [ ] 词库耗尽时能正确处理
- [ ] 无学习任务时给出明确提示

### 2.3 初步记忆

#### 用户故事

> 作为一名用户，我想先浏览今天要背的新词，看看它们的读音和意思，建立初步印象。

#### 2.3.1 展示

- 以列表方式展示今日**新词**（不含复习词）
- 默认同时展示 10 个单词/词组
- 可配置同时展示的条数：最少 1 条，最多为今日所有新词
- 如果今日新词少于配置条数，则展示全部新词
- 每个条目展示：英文单词/词组、词性（如有）、中文翻译、音标（如有）
- 列表超出展示区域时可滚动

#### 2.3.2 选择

- 鼠标悬停高亮当前选中的条目
- 键盘上/下键移动高亮选中项
- 高亮项有视觉区分（背景色变化）
- 初始状态：第一条为选中项

#### 2.3.3 播报

**触发方式**

- 鼠标点击选中条目
- 按空格键播报当前选中条目
- 可设置"选中时自动播报"（设置项，默认关闭）

**播报内容**（可配置，以下为默认值）

| 类型 | 默认播报内容 | 说明 |
|------|-------------|------|
| 单词 | 读音 → 字母拼写 | 先朗读单词，再逐字母拼读 |
| 词组 | 读音 → 中文翻译 | 先朗读词组，再朗读中文翻译 |

**播报细节**

- "读音"：调用 TTS 服务朗读英文单词/词组
- "字母拼写"：TTS 逐字母朗读，如 "apple" → "A, P, P, L, E"。字母间有短暂停顿（约 0.3 秒）
- "中文翻译"：TTS 朗读中文翻译（需 TTS 服务支持中文）
- 各段播报之间停顿约 0.5 秒
- 播报过程中再次触发播报 → 取消当前播报，重新开始
- 如果 TTS 请求失败（网络问题等），静默跳过，不阻断用户操作

**验收标准**

- [ ] 列表正确展示配置数量的新词
- [ ] 鼠标悬停和键盘上下键能正确切换选中项
- [ ] 空格键和点击能触发播报
- [ ] 单词默认播报读音+字母拼写，词组默认播报读音+中文翻译
- [ ] 自动播报设置生效
- [ ] TTS 失败时不阻断操作

### 2.4 回忆巩固

#### 用户故事

> 作为一名用户，我想通过回忆来巩固记忆，系统根据我的掌握程度自动安排复习时间。

#### 2.4.1 概述

回忆巩固阶段包含今日**所有**词表中的单词（新词 + 复习词），使用 SM-2 算法控制每个单词的重复出现间隔。

提供三种模式，用户可选择进入：

1. **英译中回忆**：展示英文，回忆中文
2. **中译英回忆**：展示中文，回忆英文
3. **混合回忆**：随机混合以上两种

#### 2.4.2 英译中回忆

**展示**

- 与初步记忆相同的列表布局，可配置同时展示条数
- 展示英文单词/词组、词性（如有）、音标（如有）
- **隐藏**中文翻译

**选择**

- 与初步记忆相同（鼠标悬停 / 键盘上下键）

**播报**

- 触发方式与初步记忆相同
- 默认播报内容：
  - 单词：读音 → 字母拼写（同初步记忆）
  - 词组：读音（**不播报中文翻译**，与初步记忆不同）
- 可自定义播报内容

**偷看**

- 每个条目右侧有"眼睛"图标按钮
- 鼠标按住眼睛图标 → 显示该条目的中文翻译
- 松开鼠标 → 再次隐藏中文翻译
- 键盘快捷键：按住 Q 键 → 显示**所有**条目的中文翻译，松开 → 隐藏
- 偷看不影响 SM-2 状态（偷看不算作一次"回忆"）

**难度评级**

- 每个条目右侧有 4 个评级按钮：Easy / Good / Hard / Forget
- 键盘快捷键：1 = Easy, 2 = Good, 3 = Hard, 4 = Forget
- 评级后：
  - 该条目从列表中移除（本轮不再展示）
  - SM-2 算法根据评级更新该词的 LearningRecord，计算下次出现时间
  - 如果下次出现时间仍在当前会话内 → 在后续轮次中再次展示
  - 如果下次出现时间超出当前会话 → 留待下次学习时复习
- 评级反馈：条目移除时有轻微的淡出动画

**循环与结束**

- 所有条目都被评级移除后 → 检查是否有词的 nextReviewTime 在当前时间之前（需要再次展示）
  - 如果有 → 将这些词重新加入列表，开始新一轮
  - 如果没有 → 本轮回忆巩固结束
- 用户可随时点击"结束"按钮退出

#### 2.4.3 中译英回忆

**展示**

- 展示中文翻译
- **隐藏**英文单词/词组
- 词性和音标也隐藏（因为它们是英文属性）

**选择**

- 与初步记忆相同

**播报**

- 默认**不播报**
- 可设置播报英文读音

**偷看**

- 眼睛图标 / Q 键 → 显示英文单词/词组（而非中文）
- 其他同英译中

**难度评级**

- 同英译中，4 个评级 + 快捷键 1/2/3/4

**循环与结束**

- 同英译中

#### 2.4.4 混合回忆

- 每个词随机分配方向（英译中 或 中译英），概率各 50%
- 列表中可能同时存在两种方向的条目
- 每个条目通过标签或小图标标识当前方向（如 "EN→ZH" / "ZH→EN"）
- 展示、播报、偷看、评级规则根据该条目分配的方向分别适用
- 循环与结束规则同上

#### 2.4.5 SM-2 调度（回忆巩固阶段）

评级后调用 SM-2 算法：

| 评级 | SM-2 quality 值 | 效果 |
|------|----------------|------|
| Easy | 5 | EF 增加，间隔大幅延长 |
| Good | 4 | EF 小幅增加，间隔延长 |
| Hard | 3 | EF 不变或微降，间隔小幅延长 |
| Forget | 0 | EF 降低，repetitionCount 归零，间隔重置为 60 秒 |

- 新词首次评级后的初始间隔：
  - Easy → 300 秒（5 分钟）
  - Good → 300 秒（5 分钟）
  - Hard → 300 秒（5 分钟）
  - Forget → 60 秒（1 分钟）

**验收标准**

- [ ] 三种模式正确展示/隐藏对应内容
- [ ] 偷看功能：鼠标按住眼睛图标和 Q 键均能正确显示/隐藏
- [ ] 评级后条目正确移除，SM-2 状态正确更新
- [ ] 需要再次复习的词在后续轮次正确出现
- [ ] 所有词复习完毕后正确结束或开始新轮次
- [ ] 混合模式中每个词方向随机分配且标识清晰

### 2.5 考察

#### 用户故事

> 作为一名用户，我想通过听写和默写来检验自己的记忆效果，系统自动判断我的掌握程度。

#### 2.5.1 概述

考察阶段也包含今日所有词表中的单词，提供两种模式：

1. **听写**：听英文，写出英文 + 中文
2. **默写**：看中文，写出英文

考察阶段同样使用 SM-2 算法控制复习间隔，但掌握程度由系统**自动判定**（基于正确性 + 时间阈值）。

#### 2.5.2 听写

**流程**

1. 系统播报英文单词/词组的读音
2. 用户在输入框中输入：
   - 英文单词/词组
   - 对应的中文翻译
3. 用户按回车提交答案
4. 系统判定并展示结果

**输入区域**

- 两个输入框：英文输入框（自动聚焦）+ 中文输入框
- 按 Tab 键在两个输入框之间切换
- 按回车键提交（在中文输入框中按回车，或在英文输入框中按回车且中文框为空时提交）

**自动判定规则**

- **英文判定**：
  - 忽略大小写
  - 忽略首尾空格
  - 词组中单词间的多个空格视为一个空格
  - 完全匹配 → 正确
  - 不匹配 → 错误
- **中文判定**：
  - 忽略首尾空格
  - 用户输入的中文翻译包含标准答案中的任一释义即算正确（标准答案中多个释义以逗号/分号分隔）
  - 完全匹配 → 正确
  - 不匹配 → 错误
- **综合判定**：
  - 英文正确 + 中文正确 → 正确
  - 其他情况 → 错误

**时间阈值自动评级**

- 计时起点：TTS 播报结束时刻
- 计时终点：用户按回车提交时刻
- 阈值（可在设置中配置，默认值）：

| 判定结果 | 耗时 | 评级 |
|----------|------|------|
| 正确 | ≤ 5 秒 | Easy (5) |
| 正确 | ≤ 10 秒 | Good (4) |
| 正确 | > 10 秒 | Hard (3) |
| 错误 | 任意 | Forget (0) |

**结果反馈**

- 正确：输入框变绿，短暂显示 "✓"，1.5 秒后自动进入下一个词
- 错误：输入框变红，显示正确答案（英文 + 中文），3 秒后自动进入下一个词
- 用户也可以不按回车，而是直接点击 "Forget" 按钮（或按 4 键）跳过并查看答案

**循环与结束**

- 同回忆巩固：所有词处理完后检查是否有需要再次复习的词
- 用户可随时退出

#### 2.5.3 默写

**流程**

1. 系统展示中文翻译
2. 用户在输入框中输入对应的英文单词/词组
3. 用户按回车提交答案
4. 系统判定并展示结果

**输入区域**

- 一个输入框：英文输入框（自动聚焦）

**自动判定规则**

- 英文判定规则同听写
- 无需输入中文，因此综合判定只看英文

**时间阈值自动评级**

- 计时起点：中文展示时刻（或页面加载完成时刻）
- 计时终点：用户按回车提交时刻
- 阈值同听写

**结果反馈**

- 同听写

**循环与结束**

- 同听写

**验收标准**

- [ ] 听写模式：TTS 播报后能正确接收输入并判定
- [ ] 默写模式：展示中文后能正确接收输入并判定
- [ ] 英文判定忽略大小写和多余空格
- [ ] 中文判定支持多释义匹配
- [ ] 时间阈值评级正确
- [ ] 错误时展示正确答案
- [ ] 能跳过（Forget）并查看答案

### 2.6 设置

#### 用户故事

> 作为一名用户，我想自定义学习参数，让学习节奏适合我自己。

#### 设置项一览

| 分组 | 设置项 | 类型 | 默认值 | 说明 |
|------|--------|------|--------|------|
| 学习计划 | 每日新词数量 | 数字输入 | 20 | 范围 1~500 |
| 初步记忆 | 同时展示条数 | 数字输入 | 10 | 范围 1~今日全部新词数 |
| 初步记忆 | 选中时自动播报 | 开关 | 关闭 | 选中条目时自动触发播报 |
| 播报设置 | 单词播报内容 | 多选 | 读音 + 字母拼写 | 可选：读音、字母拼写 |
| 播报设置 | 词组播报内容 | 多选 | 读音 + 中文翻译 | 可选：读音、中文翻译 |
| 回忆巩固 | 同时展示条数 | 数字输入 | 10 | 范围 1~今日全部词数 |
| 回忆巩固 | 英译中-单词播报内容 | 多选 | 读音 + 字母拼写 | 同播报设置 |
| 回忆巩固 | 英译中-词组播报内容 | 多选 | 读音 | 同播报设置 |
| 回忆巩固 | 中译英-默认播报 | 开关 | 关闭 | 是否播报英文读音 |
| 考察 | 同时展示条数 | 数字输入 | 5 | 范围 1~20 |
| 考察 | Easy 时间阈值 | 数字输入（秒） | 5 | 范围 1~60 |
| 考察 | Good 时间阈值 | 数字输入（秒） | 10 | 范围 Easy阈值+1~120 |
| 考察 | Hard 时间阈值 | 数字输入（秒） | 20 | 范围 Good阈值+1~300 |
| TTS | TTS 服务 | 下拉选择 | 有道词典 | 可选：有道词典、Edge TTS（后续） |

## 3. SM-2 算法规格

### 3.1 算法描述

SM-2 (SuperMemo 2) 是一种间隔重复算法，根据用户对每次复习的自评质量动态调整下次复习间隔。

### 3.2 参数

| 参数 | 说明 | 初始值 |
|------|------|--------|
| EF (Ease Factor) | 难度因子，控制间隔增长速度 | 2.5 |
| repetitionCount | 连续成功复习次数 | 0 |
| intervalSeconds | 当前复习间隔（秒） | 0 |

### 3.3 算法流程

```
输入:
  quality: Int (0-5)    // 用户评级映射
  record: LearningRecord // 当前学习记录
  now: Instant           // 当前时间

输出:
  更新后的 LearningRecord

步骤:
  1. 更新 EF:
     EF = EF + (0.8 - (5 - quality) * (0.08 + (5 - quality) * 0.02))
     if EF < 1.3: EF = 1.3

  2. 根据 quality 更新 repetitionCount 和 intervalSeconds:
     if quality < 3:
       repetitionCount = 0
       intervalSeconds = 60          // 1 分钟
     else:
       repetitionCount = repetitionCount + 1
       if repetitionCount == 1:
         intervalSeconds = 300       // 5 分钟
       elif repetitionCount == 2:
         intervalSeconds = 1800      // 30 分钟
       else:
         intervalSeconds = round(intervalSeconds * EF)

  3. 更新复习时间:
     lastReviewTime = now
     nextReviewTime = now + intervalSeconds 秒
```

### 3.4 质量映射

| 用户评级 | quality 值 | 含义 |
|----------|-----------|------|
| Easy | 5 | 轻松记住 |
| Good | 4 | 能记住，稍有犹豫 |
| Hard | 3 | 勉强记住 |
| Forget | 0 | 完全忘记 |

### 3.5 间隔增长示例（EF = 2.5 恒定）

| 次数 | 间隔 | 累计 |
|------|------|------|
| 1 | 5 分钟 | 5 分钟 |
| 2 | 30 分钟 | 35 分钟 |
| 3 | 75 分钟 | 1 小时 50 分 |
| 4 | 188 分钟 | 5 小时 |
| 5 | 469 分钟 | 12.8 小时 |
| 6 | 1173 分钟 | 32.8 小时 |
| 7 | 2931 分钟 | 3.5 天 |
| ... | ... | ... |

注：实际 EF 会随评级动态调整，上述仅为示例。

## 4. TTS 规格

### 4.1 TTS 服务

MVP 默认使用有道词典 TTS（HTTP 接口，免费，无需 API Key）。

### 4.2 播报内容类型

| 类型 | 说明 | 实现 |
|------|------|------|
| 英文读音 | 朗读英文单词/词组 | TTS 英文语音 |
| 字母拼写 | 逐字母朗读 | 每个字母单独 TTS 调用，字母间停顿 0.3 秒 |
| 中文翻译 | 朗读中文翻译 | TTS 中文语音 |

### 4.3 播报序列

播报由多个片段按顺序组成，片段之间停顿 0.5 秒。

示例——单词 "apple" 的默认播报序列：
1. 英文读音："apple"（TTS 英文语音）
2. 停顿 0.5 秒
3. 字母拼写："A" → 0.3s → "P" → 0.3s → "P" → 0.3s → "L" → 0.3s → "E"
4. 结束

示例——词组 "look forward to" 的默认播报序列：
1. 英文读音："look forward to"（TTS 英文语音）
2. 停顿 0.5 秒
3. 中文翻译："期待"（TTS 中文语音）
4. 结束

### 4.4 播报控制

- 播报过程中再次触发播报 → 取消当前，重新开始
- 切换选中项时如果开启自动播报 → 取消前一个词的播报，开始新词的播报
- 离开当前页面 → 取消所有播报

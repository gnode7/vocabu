# Vocabu 产品需求文档 (PRD)

> 版本：1.2 | 对齐日期：2026-09-09 | 初版：1.0（2026-09-03）| 状态：已对齐（需求评审完成，作为唯一权威 spec）

---

## 1. 产品概述

### 1.1 产品定位

Vocabu 是一款辅助背英语单词和词组的桌面应用，通过科学的记忆方法（艾宾浩斯遗忘曲线 + SM-2 间隔重复算法）帮助用户高效记忆英语词汇，并提供多种回忆和考察方式检验记忆效果。

### 1.2 目标用户

- 需要背诵英语单词/词组的中国用户（考研、托福、雅思、GRE、日常学习等）
- 有自定义词库需求的用户（可导入自己的词汇列表）

### 1.3 核心价值

- **自定义词库**：用户自己决定背什么词，通过 Excel 导入
- **科学复习**：SM-2 算法自动安排复习时机，避免无效重复
- **多种检验方式**：从通览浏览、回忆巩固到听写默写考察，循序渐进检验记忆效果
- **语音辅助**：TTS 播报读音和拼写，多感官记忆

### 1.4 MVP 范围

- 平台：Desktop（Windows/macOS/Linux，基于 Compose Multiplatform JVM 目标）
- 存储：纯本地存储（SQLite）
- 词库：单个全局词库
- TTS：在线 TTS 服务

## 2. 功能模块

### 2.1 词库管理

#### 用户故事

> 作为一名备考学生，我想导入一份 Excel 词汇表，这样我可以快速建立自己的词库开始背诵。

> 作为一名用户，我想手动添加/编辑/删除单词，这样我可以随时调整词库内容。

#### 2.1.1 Excel 批量导入

**格式规范**

| 列 | 字段 | 类型 | 必填 | 说明 |
|----|------|------|------|------|
| A | 单词/词组 | 文本 | 是 | 英文单词或词组，不区分大小写存储但保留原始大小写 |
| B | 词性 | 文本 | 否 | 如 n. / v. / adj. / adv. / prep. / conj. / pron. 等，可为空 |
| C | 中文翻译 | 文本 | 是 | 一个或多个中文释义，用逗号或分号分隔 |

- 第一行为表头，自动跳过
- 支持 `.xlsx` 格式（MVP）
- 文件编码：UTF-8

**导入规则**

- **去重策略**：以"单词/词组"文本为唯一键（忽略大小写），如果导入的词已存在于词库中，则**跳过**并提示用户有 N 个重复项
- **空行处理**：跳过空行
- **格式校验**：
  - A 列为空的行 → 跳过并记录
  - C 列为空的行 → 跳过并记录（翻译不能为空）
  - B 列为空 → 允许，pos 存为 null
- **导入结果反馈**：导入完成后展示统计——成功导入 N 个，跳过 M 个重复，忽略 K 个格式错误

**验收标准**

- [ ] 能正确解析符合格式规范的 .xlsx 文件
- [ ] 重复词被跳过，不产生重复数据
- [ ] 格式异常行被跳过，不影响其他行的导入
- [ ] 导入完成后展示详细的导入结果统计

#### 2.1.2 逐条管理

**添加单词**

- 弹出编辑表单（弹窗），字段：
  - 单词/词组（必填，文本输入）
  - 词性（选填，文本输入或下拉选择）
  - 中文翻译（必填，文本输入）
- 提交前校验：单词/词组和中文翻译不能为空
- 如果单词/词组已存在（忽略大小写），提示"该词已存在"，不执行添加

**编辑单词**

- 在列表中点击编辑按钮或双击行，打开编辑表单
- 编辑表单预填当前值
- 校验规则同添加

**删除单词**

- 支持单选删除（右键菜单或操作按钮）
- 支持批量选择删除（复选框 + 批量操作栏）
- 删除前弹出确认对话框："确定删除选中的 N 个单词？此操作不可撤销。"
- 删除单词时同步删除其关联的 LearningRecord

**搜索/筛选**

- 搜索框：支持按英文单词/词组（模糊匹配）和中文翻译（模糊匹配）搜索
- 筛选：可按词性筛选（如只看名词）
- 排序：默认按字母顺序，可切换为按添加时间

**验收标准**

- [ ] 能正确添加、编辑、删除单词
- [ ] 重复词添加被拦截
- [ ] 删除单词时关联的学习记录一并清除
- [ ] 搜索能正确模糊匹配中英文内容

### 2.2 学习计划

#### 用户故事

> 作为一名用户，我想设置每天背 20 个新词，系统自动帮我安排今天的学习任务。

#### 2.2.1 每日词量设置

- 在设置页配置"每日新词数量"，默认 20
- 范围：1~500（输入校验硬界）；实际生效 = min(设置值, 词库中尚未学习的总词数)
- 修改后立即生效，影响后续的"今日词表"生成

#### 2.2.2 今日词表生成

**生成时机**：进入应用时生成，**直接展示于通览（首页）**——不设「开始学习」入口，用户不点击即可见今日词表全量。

**生成规则**

1. **新词**：三面全无 LearningRecord 的单词，按添加顺序取 `dailyNewWordCount` 个
2. **复习词**：已有记录中**任一考核面** `nextReviewTime <= now` 的单词（**缺面不算到期**，不触发入场）
3. **补查**：有记录但存在缺面的单词，按「最近一次评级时间」最旧优先，最多补 `facetCatchUpQuota` 个（默认 5，0 = 关闭补查；字段名沿用 facetCatchUpQuota）
4. **今日词表** = 新词 + 复习词 + 补查词（去重，同一单词只出现一次）

**特殊情况**

- 如果词库中没有未学习的新词 → 今日无新词，仅有复习词/补查词
- 如果没有到期的复习词 → 今日仅有新词（及补查词）
- 如果三者都没有 → 提示"今日无学习任务"，引导用户去词库添加单词
- 如果剩余新词不足 dailyNewWordCount → 取全部剩余新词

**验收标准**

- [ ] 今日词表正确包含新词、复习词和补查词，且去重
- [ ] 缺面单词按最旧活动优先、不超过配额地补查入场
- [ ] 词库耗尽时能正确处理
- [ ] 无学习任务时给出明确提示

### 2.3 通览（首页）

#### 用户故事

> 作为一名用户，我想打开应用就看到今天要学的所有词，先浏览新词的读音和意思，建立初步印象。

通览即应用首页，也是三入口（通览 / 回忆 / 考察）之一。浏览**零副作用**：不建账、不改变任何词条的学习状态。

#### 2.3.1 展示

- 首页直接展示**今日词表全量**，分三组：**新词**（默认展开）、**复习**（默认收拢）、**补查**（默认收拢）
- 每组标题显示词数，点击标题展开 / 收拢该组
- 每个条目展示：英文单词/词组、词性（如有）、中文翻译、音标（如有）
- 列表超出展示区域时可滚动

#### 2.3.2 选择

- 鼠标悬停高亮当前选中的条目
- 键盘上/下键在**可见条目**间移动高亮选中项（收拢分组内的条目不参与选择）
- 高亮项有视觉区分（背景色变化）
- 初始状态：第一条为选中项

#### 2.3.3 播报

**触发方式**

- 鼠标点击选中条目
- 按空格键播报当前选中条目
- 可设置"选中时自动播报"（设置项，默认关闭）

**播报内容**（可配置，以下为默认值）

| 类型 | 默认播报内容 | 说明 |
|------|-------------|------|
| 单词 | 读音 → 字母拼写 | 先朗读单词，再逐字母拼读 |
| 词组 | 读音 → 中文翻译 | 先朗读词组，再朗读中文翻译 |

**播报细节**

- "读音"：调用 TTS 服务朗读英文单词/词组
- "字母拼写"：TTS 逐字母朗读，如 "apple" → "A, P, P, L, E"。字母间有短暂停顿（约 0.3 秒）
- "中文翻译"：TTS 朗读中文翻译（需 TTS 服务支持中文）
- 各段播报之间停顿约 0.5 秒
- 播报过程中再次触发播报 → 取消当前播报，重新开始
- 如果 TTS 请求失败（网络问题等），静默跳过，不阻断用户操作

**验收标准**

- [ ] 首页直接展示今日词表全量，三组展示与默认展开/收拢状态正确
- [ ] 组标题点击可展开 / 收拢
- [ ] 鼠标悬停和键盘上下键能正确切换选中项（跳过收拢分组）
- [ ] 空格键和点击能触发播报
- [ ] 单词默认播报读音+字母拼写，词组默认播报读音+中文翻译
- [ ] 自动播报设置生效
- [ ] TTS 失败时不阻断操作

### 2.4 回忆巩固

#### 用户故事

> 作为一名用户，我想通过回忆来巩固记忆，系统根据我的掌握程度自动安排复习时间。

#### 2.4.1 概述与工作集

回忆是**单一入口**。会话方向由设置项「回忆方向」决定：**英→中 / 中→英 / 混合**（默认混合）。以下 2.4.2–2.4.4 描述各方向的行为规格，实际会话按设置的方向执行。

**工作集规则（按考核面过滤）**：回忆会话的工作集 = 今日词表 ∩（当前方向对应考核面**到期或缺面**）。

- 英→中方向 → 英→中 面；中→英方向 → 中→英 面；混合 → 两面任一
- 新词三面全缺，在所有方向下均参与
- **未到期的已建账考核面不提前评**（保住 SM-2 间隔语义）
- 入口按钮显示今日计数 = 当前方向对应工作集词数
- 学习首页（通览）展示：今日词表全量、顶部三入口计数（回忆 N / 考察 M）、词库管理入口、设置入口

回忆巩固使用 SM-2 算法控制重复出现间隔。三个方向：

1. **英→中**：展示英文，回忆中文
2. **中→英**：展示中文，回忆英文
3. **混合**：每个条目在可评方向中随机分配（见 2.4.4）

#### 2.4.2 英→中方向

**展示**

- 与通览相同的列表布局，可配置同时展示条数
- 仅展示英文单词/词组（**不展示词性、音标**）
- **隐藏**中文翻译

**选择**

- 与通览相同（鼠标悬停 / 键盘上下键）

**播报**

- 触发方式与通览相同
- 默认播报内容：
  - 单词：读音 → 字母拼写（同通览）
  - 词组：读音（**不播报中文翻译**，与通览不同）
- 可自定义播报内容

**偷看**

- 无独立的眼睛图标；条目中**被隐藏的一侧即为偷看区**
- 鼠标按住条目的隐藏区域 → 显示该条目的中文翻译（隐藏区悬停显示「偷看 Q」提示）
- 松开鼠标 → 再次隐藏中文翻译
- 键盘快捷键：按住 Q 键 → 显示**当前选中条目**的中文翻译，松开 → 隐藏（不全部偷看）
- 偷看不影响 SM-2 状态（偷看不算作一次"回忆"）

**难度评级**

- 评级控件为**四段式进度条**：每条词条右侧一条，从左到右 4 段；列表表头在进度条上方标注「**忘 · 熟练程度 · 熟**」指示方向（左端 = 忘，右端 = 熟），段内不显示任何文字或数字
- **点亮规则**：悬停第 N 段 → 第 1…N 段预览点亮（该评级对应色）；**按下**第 N 段固定评级 → 第 1…N 段保持点亮，展示记忆进度；点亮颜色按评级从低到高为**红（1 = Forget）、橘（2 = Hard）、黄（3 = Good）、绿（4 = Easy）**——即整条以该评级对应色填充
- **悬停提示**：鼠标移到段位上浮出 tooltip——中文名后跟快捷键键位图标：**忘记 [1] / 困难 [2] / 记得 [3] / 熟练 [4]**
- 键盘快捷键：**1 = Forget, 2 = Hard, 3 = Good, 4 = Easy**（映射与段位一致）
- 评级后：
  - 该条目**置灰保留在列表中，不消失**（文本淡显示，进度条保持醒目）；**可随时重新评级修改**（会话内以最后一次评级为准）
  - **选中态自动移至下一条未评条目**；改评时选中态原地不动
  - SM-2 算法根据最终评级更新该词**对应考核面**的 LearningRecord，计算下次出现时间
  - 如果下次出现时间仍在当前会话内 → 在后续轮次中再次展示（重新评级）
  - 如果下次出现时间超出当前会话 → 留待下次学习时复习
- 评级反馈：点亮进度条 + 文本置灰；**无逐条 toast 提示**

**循环与结束**

- 全部条目评级后 → 检查是否有词的 nextReviewTime 在当前时间之前（需要再次展示）
  - 如果有 → 将这些词重新加入列表，开始新一轮；**每轮开始时随机打乱顺序，轮内顺序固定**
  - 如果没有 → 本轮回忆巩固结束
- 用户可随时点击"结束"按钮退出

#### 2.4.3 中→英方向

**展示**

- 展示中文翻译
- **隐藏**英文单词/词组（词性、音标同属英文属性，一律不展示）

**选择**

- 与通览相同

**播报**

- 默认**不播报**
- 可设置播报英文读音

**偷看**

- 按住隐藏区域 / 按住 Q（选中条目）→ 显示英文单词/词组（而非中文）
- 其他同英→中方向

**难度评级**

- 同英→中方向，4 个评级 + 快捷键 1/2/3/4

**循环与结束**

- 同英→中方向

#### 2.4.4 混合方向

- 工作集 = 今日词表 ∩（英→中 或 中→英 至少一面到期或缺面）
- 每个条目的方向分配：在**可评方向**中随机——两面皆可评 → 各 50%；仅一面可评 → 固定为该面
- **列位固定**：英文恒在左列、中文恒在右列；英→中条目隐藏中文（右列），中→英条目隐藏英文（左列）
- 条目**不以徽章标识方向**：方向由隐藏侧体现
- 展示、播报、偷看、评级规则根据该条目分配的方向分别适用，评级写入对应考核面账本
- 循环与结束规则同上

#### 2.4.5 SM-2 调度（回忆巩固阶段）

评级后调用 SM-2 算法，**评级写入该次回忆方向对应的考核面账本**：英→中 → 英→中；中→英 → 中→英；混合按该条目分配的方向：

| 评级 | SM-2 quality 值 | 效果 |
|------|----------------|------|
| Easy | 5 | EF 增加，间隔大幅延长 |
| Good | 4 | EF 小幅增加，间隔延长 |
| Hard | 3 | EF 不变或微降，间隔小幅延长 |
| Forget | 0 | EF 降低，repetitionCount 归零，间隔重置为 60 秒 |

- 新词首次评级后的初始间隔：
  - Easy → 300 秒（5 分钟）
  - Good → 300 秒（5 分钟）
  - Hard → 300 秒（5 分钟）
  - Forget → 60 秒（1 分钟）

**验收标准**

- [ ] 各方向正确展示/隐藏对应内容（回忆列表不展示词性、音标）
- [ ] 偷看功能：按住条目隐藏区域和按住 Q（选中条目）均能正确显示/隐藏
- [ ] 评级后条目置灰保留、可随时改评（会话内最后一次评级生效）；首次评级后选中态自动移至下一条未评条目
- [ ] 评级控件为四段式进度条，表头标注「忘 · 熟练程度 · 熟」；点击第 N 段点亮前 N 段，颜色按评级为红/橘/黄/绿；无文字标签，无逐条 toast
- [ ] 需要再次复习的词在后续轮次正确出现（置灰解除）
- [ ] 所有词评级完毕后正确结束或开始新轮次
- [ ] 混合方向中按可评面分配（两面皆可评时 50/50），方向由隐藏侧体现
- [ ] 设置中修改「回忆方向」后，入口计数与工作集随之变化

### 2.5 考察

#### 用户故事

> 作为一名用户，我想通过听写和默写来检验自己的记忆效果，系统自动判断我的掌握程度。

#### 2.5.1 概述

考察是**单一入口**。会话方式由设置项「考察方式」决定：**听写 / 默写 / 混合**（默认混合）。

考察的工作集同样按考核面过滤：**听写** = 今日词表 ∩（听→拼 或 英→中 到期或缺面）；**默写** = 今日词表 ∩（中→英 到期或缺面）；**混合** = 两部分工作集的并集，会话先执行听写部分，完成后接续默写部分。工作集筛选只决定**哪些词进入会话**；进入后，该作答形态对应的全部考核面都判定并落账（含未到期面，见 2.5.2 评级去向与 ADR 0006）。

考察会话包含**轮次循环**（与回忆页同构）：答错的考核面按 SM-2 正常排期（Forget → 60 秒后到期），轮末检查会话内到期面并洗牌重现，不限次数；计时 = **焦点注意力时间**（可被切走暂停，此为明确语义，非漏洞）。

两种作答形态：

1. **听写**：听英文，写出英文 + 中文
2. **默写**：看中文，写出英文

考察为**单焦点模式**：一次只作答一个词，无多词同屏。

作答形态与考核面的对应：**听写** → 听→拼 + 英→中（双评分，见 2.5.2）；**默写** → 中→英。

考察阶段同样使用 SM-2 算法控制复习间隔，但掌握程度由系统**自动判定**（基于正确性 + 时间阈值）。

#### 2.5.2 听写

听写一次检验两个考核面：**听→拼**（听音写拼写）与**英→中**（听音写释义）。两个部分**分别计时、分别判定、分别评级、分别写入各自账本**——各部分只累计其输入框获得焦点的时长，焦点切换即暂停/恢复。

**流程**

1. 系统播报读音；播报结束 → 两个输入框**各自的倒计时圆圈**开始走（显示在输入框右侧；各圈只累计该部分获得焦点的时长：焦点在哪个框，哪个框的圈计时继续，另一个圈的计时暂停；Easy 阈值内绿色，超过变黄，Good 阈值走满一圈后变 Hard 橙色）
2. 作答中，每个输入框内靠右显示「完成 ⏎」提示（键帽图标）
3. **第一次回车**：当前输入框停止计时、内容锁定，焦点切换到另一个框（**锁定即终局**：提交前不可回改——回车 = 「这部分我说完了」；手滑的代价由提交后立刻可见的红叉与正确答案补偿）
4. **第二次回车**：两部分全部停止计时，提交批改（点击「提交」按钮 = 直接提交批改，跳过锁定阶段）
5. **批改**：两框的倒计时圈变为**绿色对号 / 红叉**徽章（答对绿底白勾 / 答错红底白叉）；答对的输入框绿底；答错的输入框**红底红边框**，正确答案以**深色文字**展示在其右侧固定槽位（框内不显示勾叉）；有错播发短促告警音；**各部分评级进度条**点亮并展示在各自输入框下方（评级 = 该部分累计耗时所定）；答错自动回放一次（英文 = 读音 + 字母拼写，中文 = 释义；可在设置关闭）
6. 提交后按钮文字变「下一个」并**获得焦点**，回车进入下一词；「**上一个**」随时回看已答词（只读、不重复落账）；无自动跳转

**输入区域**

- 两个输入框**固定宽度**（缩短），右侧留出固定槽位放倒计时圈、批改徽章与正确答案
- Tab 在两个输入框间切换；**允许先作答任一部分**
- **Tab 被捕获**：仅在**可用输入框**间循环，不会落到「提交 / 上一个 / 退出」按钮上（防止误落按钮后回车误提交）；批改后输入框禁用，焦点由系统移交「下一个」按钮（不属于 Tab 链）
- **部分留空提交 = 该部分按 Forget 处理**（放弃 = 不会）

**判定与评级（两部分独立，规则相同）**

- **英文部分判定**（听→拼 面）：忽略大小写、忽略首尾空格；词组中单词间的多个空格视为一个空格；完全匹配 → 正确
- **中文部分判定**（英→中 面）：忽略首尾空格；**对称拆分**——用户输入与标准答案均按中英文标点（，,；;）拆段，用户输入的**每一段**是标准答案中某一释义的子串即该段命中，全部段命中 → 正确（支持一次拼接多个义项，如「详尽；精心」）；仅一段时退化为普通子串匹配
- 每部分按「正确性 + 该部分累计计时」自动评级（计时只累计焦点时长；阈值共用设置中的考察阈值）：

| 判定结果 | 耗时 | 评级 |
|----------|------|------|
| 正确 | ≤ Easy 阈值（默认 5 秒） | Easy (5) |
| 正确 | ≤ Good 阈值（默认 10 秒） | Good (4) |
| 正确 | > Good 阈值 | Hard (3) |
| 错误 / 留空 | 任意 | Forget (0) |

- 评级去向：英文部分 → **听→拼** 账本；中文部分 → **英→中** 账本。**两面全部落账**——即使某面并不在今日到期集内：该次作答等效于提前复习，SM-2 据实绩推后其到期；尚无记录的面顺带覆盖「缺面」状态（见 ADR 0006）

**结果反馈**

- 批改后每个输入框：倒计时圈变对号/红叉徽章 + 框体绿底/红底 + 该部分评级进度条（框下方）
- 无逐条 toast 提示（回放提示除外）

**循环与结束**

- **提交即落账**：每词批改完成立刻写入各考核面账本（SM-2 更新）并 upsert 当日统计，不等会话结束；中途退出时已答词不丢
- **答错面即时重排**：Forget 评级按 SM-2 重置间隔（60 秒后到期），**会话内轮末重现**——本轮全部答完后检查会话内到期面，有则洗牌开新轮（词粒度：整词重考，两面同判同落账，见 ADR 0006），无则结束；重现次数不限，直到会话内无到期面
- 「上一个」可回看已答词的判定结果；用户可随时退出（已答词已落账）
- 听写部分轮次循环结束后：进入默写部分（考察方式 = 混合时）或结束

#### 2.5.3 默写

**流程**

1. 系统展示中文翻译与词性；输入框右侧的**倒计时圆圈**开始走（计时起点 = 中文展示时刻；颜色规则同听写）
2. 作答中，输入框内靠右显示「完成 ⏎」提示（键帽图标）
3. **回车即提交批改**（单框，无锁定阶段）：倒计时圈变为**绿色对号 / 红叉**徽章；答对绿底；答错**红底红边框**，正确答案以**深色文字**展示在右侧固定槽位；有错播发短促告警音；**评级进度条**点亮并展示在输入框下方；答错自动回放读音（可在设置关闭）
4. 提交后按钮文字变「下一个」并获得焦点，回车进入下一词；「上一个」随时回看（只读）；无自动跳转

**输入区域**

- 一个输入框：英文输入框（自动聚焦），固定宽度；右侧固定槽位放倒计时圈、批改徽章与正确答案

**自动判定规则**

- 英文判定规则同听写
- 无需输入中文，因此判定只看英文

**时间阈值自动评级**

- 计时起点：中文展示时刻（或页面加载完成时刻）
- 计时终点：用户按回车提交时刻
- 阈值同听写
- 评级去向：**中→英** 账本

**结果反馈**

- 同听写（单输入框）：圈变对号/红叉徽章 + 框体绿底/红底 + 深色正确答案 + 评级进度条（框下方）
- 无逐条 toast 提示（回放提示除外）

**循环与结束**

- **提交即落账**（同听写）；**Forget 面 60 秒后到期，会话内轮末重现**（默写词粒度，整词重考），不限次数，直到会话内无到期面
- 提交后按钮变「下一个」（回车触发，焦点在按钮上），无自动跳转；「上一个」可回看；**Tab 被捕获**（仅输入框）
- 用户可随时退出（已答词已落账）

**验收标准**

- [ ] 听写模式：TTS 播报后能正确接收输入并判定
- [ ] 听写两部分分别计时、分别判定、分别评级、分别入账（英文→听拼，中文→英中）
- [ ] **每框独立倒计时圈**：只累计该框焦点时长，另一框暂停；颜色随阈值切换（绿→黄→走满变橙）
- [ ] **回车状态机**：第一次锁定当前框并切换焦点，第二次提交批改；提交后按钮变「下一个」且获得焦点，回车进入下一词

## 3. SM-2 算法规格

### 3.1 算法描述

SM-2 (SuperMemo 2) 是一种间隔重复算法，根据用户对每次复习的自评质量动态调整下次复习间隔。

### 3.2 参数

| 参数 | 说明 | 初始值 |
|------|------|--------|
| EF (Ease Factor) | 难度因子，控制间隔增长速度 | 2.5 |
| repetitionCount | 连续成功复习次数 | 0 |
| intervalSeconds | 当前复习间隔（秒） | 0 |

### 3.3 算法流程

```
输入:
  quality: Int (0-5)    // 用户评级映射
  record: LearningRecord // 当前学习记录
  now: Instant           // 当前时间

输出:
  更新后的 LearningRecord

步骤:
  1. 更新 EF:
     EF = EF + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02))
     if EF < 1.3: EF = 1.3

  2. 根据 quality 更新 repetitionCount 和 intervalSeconds:
     if quality < 3:
       repetitionCount = 0
       intervalSeconds = 60          // 1 分钟
     else:
       repetitionCount = repetitionCount + 1
       if repetitionCount == 1:
         intervalSeconds = 300       // 5 分钟
       elif repetitionCount == 2:
         intervalSeconds = 1800      // 30 分钟
       else:
         intervalSeconds = round(intervalSeconds * EF)

  3. 更新复习时间:
     lastReviewTime = now
     nextReviewTime = now + intervalSeconds 秒
```

### 3.4 质量映射

| 用户评级 | quality 值 | 含义 |
|----------|-----------|------|
| Easy | 5 | 轻松记住 |
| Good | 4 | 能记住，稍有犹豫 |
| Hard | 3 | 勉强记住 |
| Forget | 0 | 完全忘记 |

### 3.5 间隔增长示例（EF = 2.5 恒定）

| 次数 | 间隔 | 累计 |
|------|------|------|
| 1 | 5 分钟 | 5 分钟 |
| 2 | 30 分钟 | 35 分钟 |
| 3 | 75 分钟 | 1 小时 50 分 |
| 4 | 188 分钟 | 5 小时 |
| 5 | 469 分钟 | 12.8 小时 |
| 6 | 1173 分钟 | 32.8 小时 |
| 7 | 2931 分钟 | 3.5 天 |
| ... | ... | ... |

注：实际 EF 会随评级动态调整，上述仅为示例。

## 4. TTS 规格

### 4.1 TTS 服务

MVP 默认使用有道词典 TTS（HTTP 接口，免费，无需 API Key）。

### 4.2 播报内容类型

| 类型 | 说明 | 实现 |
|------|------|------|
| 英文读音 | 朗读英文单词/词组 | TTS 英文语音 |
| 字母拼写 | 逐字母朗读 | 每个字母单独 TTS 调用，字母间停顿 0.3 秒 |
| 中文翻译 | 朗读中文翻译 | TTS 中文语音 |

### 4.3 播报序列

播报由多个片段按顺序组成，片段之间停顿 0.5 秒。

示例——单词 "apple" 的默认播报序列：
1. 英文读音："apple"（TTS 英文语音）
2. 停顿 0.5 秒
3. 字母拼写："A" → 0.3s → "P" → 0.3s → "P" → 0.3s → "L" → 0.3s → "E"
4. 结束

示例——词组 "look forward to" 的默认播报序列：
1. 英文读音："look forward to"（TTS 英文语音）
2. 停顿 0.5 秒
3. 中文翻译："期待"（TTS 中文语音）
4. 结束

### 4.4 播报控制

- 播报过程中再次触发播报 → 取消当前，重新开始
- 切换选中项时如果开启自动播报 → 取消前一个词的播报，开始新词的播报
- 离开当前页面 → 取消所有播报
- TTS 请求失败 → 静默跳过该段播报，不阻断操作
- **失败时的计时回退**：听写计时起点为「播报结束」；TTS 失败导致播报未发生时，计时起点回退为该词条展示时刻
- **音频缓存**：字母音频永久缓存本地（26 个字母 + 变体，首次联网获取后离线可用）；整词/词组读音 LRU 缓存（上限 200 条）

- 屏幕分辨率：最低 1280x720，推荐 1920x1080

### 6.3 数据安全

- 本地数据库文件存储在用户数据目录
- 无网络传输用户数据（TTS 请求仅发送待播报文本）

### 6.4 后续扩展（不在 MVP 范围）

- 多词库支持
- 服务端同步
- iOS / Android / Web 客户端
- 学习统计图表
- 单词本/收藏功能
- 考察结束汇总页（判定数 / 正确率 / 评级分布 / 总用时）
- 通览页展示各考核面到期状态灯（面粒度详情更适合词库管理页）

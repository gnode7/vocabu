我想要开发一个辅助背英语单词和检查记忆效果的软件。代码框架已搭好，就在 'code' 目录下，采用 Kotlin Multiplatform 和 Compose Multiplatform 技术栈，包含 iOS、Android、Web、桌面端，以及服务端代码。但先别忙着写代码，先和我一起设计下需求，并计划下开发步骤。我目前设想的功能主要有： 

1. 建立词库：逐个录入或批量导入要背的单词/词组、词性和对应的中文翻译。 
2. 学习计划：设置每天要背的单词/词组量，或指定今天要背的单词/词组清单。 
3. 初步记忆：完整展示单词/词组的中英文，进行初步记忆。
   1. 展示：以列表方式默认展示10个单词/词组。可以设置同时展示的单词/词组条数，最少1条，最多为今天要背的所有单词/词组。
   2. 选择：鼠标悬停或键盘上下键高亮当前选中的单词/词组。
   3. 播报：鼠标点击或按空格键，语音播报当前单词/词组。可以设置选中当前单词/词组时自动播报。
   4. 播报的内容包含：单词/词组读音、字母拼写、中文翻译。用户可设置语音播报的内容。默认播报内容为：
      1. 单词：读音、字母拼写。
      2. 词组：读音、中文翻译。
4. 回忆巩固：可选择如下三种回忆方式：
   1. 英译中回忆：隐藏单词/词组的中文，依次让用户回忆中文翻译。
      1. 展示：与初步记忆相同。
      2. 选择：与初步记忆相同。
      3. 播报：词组默认设置不播报中文翻译，其他与初步记忆相同。
      4. 偷看：用户可以用鼠标按住每个条目右边“眼睛”图标，或按下 Q 建以展示中文翻译，松开则再次隐藏。
      5. 每个单词可以勾选回忆的难度：Easy（轻松）、Good（能答对）、Hard（勉强答对）、Forget（忘记），键盘快捷键分别为 1、2、3、4
      6. 循环随机展示要背的单词/词组。根据艾宾浩斯遗忘曲线的思想，使用SM-2算法（用E-Factor控制的递增间隔）控制重复出现的间隔和次数。
   2. 中译英回忆：隐藏单词/词组的英文，只展示中文，依次让用户回忆英文拼写。
      1. 展示：与初步记忆相同。
      2. 选择：与初步记忆相同。
      3. 播报：默认不播报，可设置播报单词/词组的英文读音。
      4. 偷看：用户可以用鼠标按住每个条目右边“眼睛”图标，或按下 Q 建以展示英文单词/词组，松开则再次隐藏。
      5. 每个单词可以勾选掌握的程度：Easy（轻松）、Good（知晓）、Hard（勉强知晓）、Forget（忘记），键盘快捷键分别为 1、2、3、4
      6. 循环随机展示要背的单词/词组。根据艾宾浩斯遗忘曲线的思想，使用SM-2算法（用E-Factor控制的递增间隔）控制重复出现的间隔和次数。
   3. 中译英、英译中混合回忆。
5. 考察
   1. 听写：播报英文，输入该单词/词组和对应中文
      1. 根据输入是否正确，以及输入完成的时长，自动判断用户掌握这个单词/词组的程度：Easy（轻松）、Good（知晓）、Hard（勉强知晓）、Forget（忘记）。
      2. 答错的单词展示正确答案，并标记为 Forget。用户也可以直接选择 Forget，并查看答案。
      3. 循环随机展示要背的单词/词组。根据艾宾浩斯遗忘曲线的思想，使用SM-2算法（用E-Factor控制的递增间隔）控制重复出现的间隔和次数。
   2. 默写：展示中文，输入对应的英文单词/词组
      1. 根据输入是否正确，以及输入完成的时长，自动判断用户掌握这个单词/词组的程度：Easy（轻松）、Good（知晓）、Hard（勉强知晓）、Forget（忘记）。
      2. 答错的单词展示正确答案，并标记为 Forget。用户也可以直接选择 Forget，并查看答案。
      3. 循环随机展示要背的单词/词组。根据艾宾浩斯遗忘曲线的思想，使用SM-2算法（用E-Factor控制的递增间隔）控制重复出现的间隔和次数。
